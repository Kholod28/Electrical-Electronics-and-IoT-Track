DC Motors Control Using L293D

Description

This task demonstrates controlling four DC motors using an Arduino Uno and L293D motor drivers.

Motion Sequence

The four DC motors are programmed to perform the following movements:

Forward: All four motors move forward for 30 seconds.
Backward: All four motors reverse direction and move backward for 60 seconds.
Right and Left: The motors alternate their directions to simulate turning right and left for 60 seconds.

Components

Arduino Uno R3
4 DC Motors
2 × L293D Motor Driver
Breadboard
Jumper Wires
9V Battery

Simulation

The circuit was built and tested using Tinkercad.

Result

All four DC motors were successfully controlled and operated according to the required movement sequence.
