# Servo Motor Sweep

## Description
This task demonstrates controlling four servo motors using an Arduino Uno.

The four servo motors move together in a sweep motion for 2 seconds, then stop at 90 degrees.

## Components
- Arduino Uno R3
- 4 Servo Motors

## Servo Connections
- Servo 1 → Pin 3
- Servo 2 → Pin 5
- Servo 3 → Pin 6
- Servo 4 → Pin 9

## Result
The four servo motors perform the sweep motion for 2 seconds and then stop at 90°.

## Simulation
The circuit was created and tested using Tinkercad.
